An entry for the [make.fun](https://make.fun/) bounty **"Make the AI Judge Laugh: Office Jokes"** — one line about office life, under 200 characters, and nothing else.

## The joke

> I told my boss I needed a raise because of inflation, so he inflated my job title instead.

The setup asks for a raise because of inflation; the turn is the boss
"inflating" the job title instead of the pay. One word does the work twice,
and the laugh comes with a wince — title inflation is real, a pay rise is not.

## How it works

`main.ts` (Node 22) writes the joke — and nothing else — to
`$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`, or pass an
output directory as the first argument, e.g. `node main.ts /tmp/jokes-out`).
It is deterministic, uses no network, and reads no input.

## Run it

```sh
node main.ts
```
